{# Shared wind-arrow macro (km/h) — imported by plan.html and analysis_detail.html so the forecast and historical per-stop wind cells render identically. De-branded from Team Asha's ride_plan_detail.html wind_arrow macro: same SVG arrow + color rules, but sized/labeled in km/h (BrevetHub's km / km-h convention) instead of mph. `w` is a per-stop wind dict (from shared.weather.compute_stop_winds or the analysis historical assembler): wind_speed_kmh, wind_type, and either arrow_rotation or the legacy wind_arrow_deg. Renders nothing when `w` is None (no forecast for that stop), so the caller can lay out one cell per stop and coordinate-less/unresolved stops simply stay blank. #} {% macro wind_arrow(w, show_speed=true) %} {% if w %} {% set color = '#dc2626' if w.wind_type == 'headwind' else '#16a34a' if w.wind_type == 'tailwind' else '#1e293b' %} {% set kmh = (w.wind_speed_kmh|default(0))|round(0)|int %} {% set sz = 14 if kmh < 13 else 18 if kmh < 24 else 22 if kmh < 40 else 26 %} {% set sw = 1.5 if kmh < 13 else 2 if kmh < 24 else 2.5 if kmh < 40 else 3 %} {# Arrow points where the wind travels in the rider's frame — exact angle from the rotation: headwind=↓ (into the face), tailwind=↑ (from behind), crosswind sideways. #} {% set rotation = w.arrow_rotation if w.arrow_rotation is defined else (w.wind_arrow_deg if w.wind_arrow_deg is defined else (180 if w.wind_type == 'headwind' else 0 if w.wind_type == 'tailwind' else 90)) %} {% if show_speed %}{{ kmh }}{% endif %} {% endif %} {% endmacro %}
