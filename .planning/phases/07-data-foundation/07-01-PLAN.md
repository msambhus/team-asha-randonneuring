```python
def get_database_url():
    """Get database URL from environment."""
    env_file = Path(__file__).parent.parent / '.env'
    if env_file.exists():
        with open(env_file) as f:
            for line in f:
                if line.startswith('DATABASE_URL='):
                    return line.strip().split('=', 1)[1]
    return os.getenv('DATABASE_URL')
```

Tables (all SQL copied from 07-RESEARCH.md Code Examples section with these exact constraints):

1. **personality_profile**: `id SERIAL PRIMARY KEY`, `rider_id INTEGER NOT NULL REFERENCES rider(id) ON DELETE CASCADE`, `profile_type VARCHAR(10) NOT NULL CHECK (profile_type IN ('coach', 'rider'))`, typed fields with CHECK constraints for tone/humor_type/directness/preferred_formality/humor_sensitivity/encouragement_style/technical_depth, TEXT[] arrays for signature_phrases/topic_biases/topics_allowed, extraction metadata columns (extraction_source, extraction_date, source_message_count, extraction_confidence), audit columns (created_at, updated_at, updated_by, deleted_at), `UNIQUE (rider_id, profile_type)`. Indexes on rider_id and profile_type.

2. **gear_preference**: `id SERIAL PRIMARY KEY`, `rider_id INTEGER NOT NULL UNIQUE REFERENCES rider(id) ON DELETE CASCADE`, bike fields (make VARCHAR(100), model VARCHAR(100), year INTEGER, material VARCHAR(20) with CHECK), category fields (wheels_tires, lighting, bags, navigation, kit as TEXT), value_orientation VARCHAR(20) with CHECK, audit columns. Index on rider_id.

3. **coach_assignment**: `id SERIAL PRIMARY KEY`, `coach_rider_id INTEGER NOT NULL REFERENCES rider(id) ON DELETE CASCADE`, `topic_domain VARCHAR(50) NOT NULL`, `is_default BOOLEAN DEFAULT FALSE`, `is_active BOOLEAN DEFAULT TRUE`, audit columns, `UNIQUE (coach_rider_id, topic_domain)`. Indexes on coach_rider_id, topic_domain, and partial index on is_active.

4. **coaching_guardrail**: `id SERIAL PRIMARY KEY`, `rule_type VARCHAR(30) NOT NULL CHECK (rule_type IN ('topic_block', 'tone_limit', 'escalation', 'scope'))`, `rule_value TEXT NOT NULL`, `applies_to VARCHAR(10) DEFAULT 'all' CHECK (applies_to IN ('all', 'shriram', 'venki'))`, `is_active BOOLEAN DEFAULT TRUE`, `rule_version INTEGER DEFAULT 1`, audit columns. Indexes on rule_type and partial index on is_active.

5. **Trigger**: `increment_guardrail_rule_version()` function + `trigger_increment_guardrail_rule_version` BEFORE UPDATE trigger on coaching_guardrail that sets `NEW.rule_version = OLD.rule_version + 1` and `NEW.updated_at = NOW()`.

CRITICAL constraints from research:
- Use `VARCHAR(N)` with CHECK constraints, NOT free-text TEXT columns (OWASP LLM01 defense per PROF-01)
- Use `CREATE INDEX IF NOT EXISTS` (NOT `CONCURRENTLY` -- tables are new and empty, avoids Supabase pooler issues)
- Include `deleted_at TIMESTAMPTZ` on all four tables for soft-delete
- Include `updated_at`, `updated_by` on all four tables for audit (PROF-05)
