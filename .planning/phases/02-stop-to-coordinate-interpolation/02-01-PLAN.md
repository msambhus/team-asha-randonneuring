    - test_interpolated_between_points: A stop at 5.0 miles (8047m) on a track with points at 0m and 16093m returns lat/lng halfway between those two points
    - test_40_mile_stop_unit_conversion: A stop at 40.0 miles on a track spanning 0m to 80000m. The returned lat/lng must be within 0.5 km of the correct position at 64374m (40 * 1609.344). This validates miles-to-meters conversion is correct — NOT placing the stop at 40 meters.
    - test_beyond_track_end_clamped: A stop at 999.0 miles on a track ending at 100000m returns the lat/lng of the final track point (no error)
    - test_start_stop_returns_first_point: A stop at 0.0 miles returns the lat/lng of the first track point
    - test_empty_track_returns_none: An empty track_points list returns [None] * len(stops)
    - test_skips_none_coordinates: Track points with y=None or x=None are filtered out; interpolation uses remaining valid points
    - test_zero_length_segment: Two consecutive track points with identical d values do not cause ZeroDivisionError
    - test_multiple_stops_ordered: Three stops at different distances return three coordinates in correct order
  </behavior>

       - Accept stops (list of dicts with 'distance_miles') and track_points (list of RWGPS dicts with y, x, d)
       - Return list of {'lat': float, 'lng': float} in same order as stops, or None for unresolvable stops

       - For each stop: convert distance_miles to meters via MILES_TO_METERS, then linear scan to find bounding segment, then interpolate
       - Clamp: stops at/before start -> first point; stops at/beyond end -> last point
