1. Add two new functions to models.py at the end of the PERSONALITY & COACHING section:

   a. `get_trait_evidence(rider_id, extraction_source=None)` — queries `personality_trait_evidence` table. If extraction_source provided, filter by it. Returns list of dicts ordered by trait_name, created_at DESC. Always filters `WHERE rider_id = %s`.

   b. `get_all_guardrails(rule_type=None)` — queries `coaching_guardrail` where `deleted_at IS NULL` (does NOT filter on is_active — shows all for admin). Optional rule_type filter. Order by rule_type, id. Returns list of dicts.

2. Add personality admin routes to routes/admin.py. Add these imports at the top:
   `get_all_personality_profiles, get_personality_profile, upsert_personality_profile, get_trait_evidence, get_rider_by_id`

   Define PERSONALITY_ENUMS and COACH_TRAIT_FIELDS as module-level constants in admin.py (see interfaces block for values).

   Define `compute_completeness(profile)` helper that counts non-null/non-empty trait fields from COACH_TRAIT_FIELDS. Returns (filled, total, confidence).

   Routes:
   a. `GET /admin/personalities` — calls get_all_riders() and get_all_personality_profiles(). Builds a dict of profiles keyed by rider_id (prefer extraction_source='merged', then 'manual', then 'whatsapp'). Computes completeness per rider. Renders `admin/personalities.html` with riders, profiles dict, completeness dict.

   b. `GET /admin/personalities/<int:rider_id>` — loads rider via get_rider_by_id, profile via get_personality_profile (query for 'merged' first, fallback to 'manual', then any), evidence via get_trait_evidence(rider_id). Renders `admin/personality_edit.html` with rider, profile, evidence, PERSONALITY_ENUMS, COACH_TRAIT_FIELDS.

   c. `POST /admin/personalities/<int:rider_id>` — extracts form fields, handles array fields (signature_phrases, topic_biases, topics_allowed) by splitting newline-separated textarea values into lists. Passes `extraction_source='manual'` in the fields dict (critical: prevents overwriting merged/whatsapp rows). Calls upsert_personality_profile(rider_id, 'coach', fields, updated_by='admin'). Flash success, redirect back to edit page.

   All routes: use @user_login_required decorator, call _require_admin().

   Do NOT implement re-extraction as subprocess. ADMN-05 is satisfied by displaying last extraction timestamp and a copyable CLI command string on the edit page.
