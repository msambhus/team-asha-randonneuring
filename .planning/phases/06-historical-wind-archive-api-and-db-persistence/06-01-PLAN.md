- Uses `_execute("SELECT * FROM ride_wind_data WHERE ride_id = %s ORDER BY stop_order", (ride_id,)).fetchall()`
- Returns `list(rows)` (empty list if no rows)

`save_ride_wind_data(ride_id, wind_rows)`:
- Gets connection via `get_db()`
- Loops through `wind_rows`, executing INSERT with ON CONFLICT (ride_id, stop_order) DO NOTHING

- Column list: ride_id, stop_order, stop_name, wind_speed_kmh, wind_direction_deg, headwind_kmh, crosswind_kmh, wind_type, temperature_c, conditions, data_source

IMPORTANT: `get_db()` sets `autocommit = False`, so `save_ride_wind_data` must explicitly call `conn.commit()`. This is the only model function that writes wind data — it needs its own commit (not relying on auto-rollback from the test fixture).
