  <action>
Create `scripts/personality_helpers.py` with these components:

**1. Pydantic models (PersonalityExtraction, TraitEvidence):**
```python
class TraitEvidence(BaseModel):
    quotes: list[str] = Field(max_length=5)  # 3-5 verbatim quotes, each max 200 chars

class PersonalityExtraction(BaseModel):
    tone: Literal['direct', 'warm', 'playful', 'serious', 'sarcastic']
    humor_type: Literal['none', 'dry', 'sarcastic', 'gentle', 'self-deprecating']
    directness: Literal['low', 'medium', 'high']
    encouragement_style: Literal['data-driven', 'emotional', 'balanced', 'tough-love']
    technical_depth: Literal['beginner', 'intermediate', 'expert']
    domain_bias: Optional[str] = None
    response_length_tendency: Literal['brief', 'moderate', 'verbose']
    question_asking_behavior: Literal['rarely', 'sometimes', 'frequently']
    signature_phrases: list[str] = Field(max_length=5)
    tone_evidence: TraitEvidence
    humor_evidence: TraitEvidence
    directness_evidence: TraitEvidence
    signature_phrase_evidence: TraitEvidence
```

**2. EXTRACTION_SYSTEM_PROMPT:** Use the prompt from 08-RESEARCH.md code examples section verbatim. This is the prompt that tells GPT-4o how to classify personality traits.

**3. group_by_sender(filepath: str) -> dict[str, list[dict]]:**
- Import `parse_export` and `MEDIA_SKIP_PATTERNS` from `scripts.whatsapp_parser`
- Parse all messages, then group by sender
- Filter out: `is_system=True`, content matching MEDIA_SKIP_PATTERNS, `len(content.split()) < 3`, URL-only messages (`startswith('https://') and ' ' not in content`)
- Return dict mapping sender name to list of qualifying messages

**4. compute_confidence(qualifying_message_count: int) -> str:**
- `>= 50` -> 'high', `>= 20` -> 'medium', else 'low'

**5. sample_messages(messages: list[dict], max_count: int = 200) -> list[dict]:**
- If len(messages) <= max_count, return all
- Otherwise, sample evenly across the time range (not just first 200 — spread across the date range for representative coverage)

**6. extract_from_messages(client: OpenAI, messages: list[dict], sender_name: str) -> PersonalityExtraction:**
- Sample messages using sample_messages()
- Format as `[YYYY-MM-DD] content` lines
- Call `client.chat.completions.parse()` with model='gpt-4o', temperature=0, response_format=PersonalityExtraction
- Return parsed result

**7. store_extraction_results(cur, rider_id, extraction: PersonalityExtraction, extraction_source: str, message_count: int):**
- Build fields dict from extraction model fields (excluding evidence fields)
- Add extraction metadata: extraction_source, extraction_date=today, source_message_count, extraction_confidence=compute_confidence(message_count)
- Use the same upsert pattern as seed_coaching_profiles.py: INSERT ... ON CONFLICT (rider_id, profile_type, extraction_source) DO UPDATE SET ...
- profile_type = 'coach' for coaches, determined by caller

**8. store_evidence(cur, rider_id, extraction: PersonalityExtraction, extraction_source: str):**
- DELETE existing evidence for (rider_id, extraction_source) first — makes re-extraction idempotent
- For each evidence field (tone_evidence, humor_evidence, directness_evidence, signature_phrase_evidence): INSERT rows into personality_trait_evidence with trait_name and each quote
- Truncate each quote to 500 chars

Include the sys.path setup at the top: `_project_root = Path(__file__).resolve().parent.parent; sys.path.insert(0, str(_project_root))`

Use `from dotenv import load_dotenv` and `load_dotenv()` for env loading (consistent with existing scripts).

<task type="auto">
  <name>Task 2: Create extract_personality_whatsapp.py CLI script</name>
  <files>scripts/extract_personality_whatsapp.py</files>
  <action>
Create `scripts/extract_personality_whatsapp.py` as a standalone CLI script. Follow the exact pattern of `scripts/import_whatsapp.py` for argparse structure, DB connection, and error handling.

**CLI arguments:**
- `--path` (required): Path to WhatsApp chat export (.txt file or .zip file)
- `--sender` (required): Sender name to extract (case-insensitive prefix match)
- `--profile-type` (default: 'coach'): 'coach' or 'rider'
- `--dry-run` (flag): Output extracted JSON to stdout, do not write to DB
- `--max-sample` (default: 200): Max messages to sample for LLM

**Script flow:**
1. Parse args
2. Handle ZIP input: if path ends with `.zip`, use `zipfile.ZipFile` to extract, find the `.txt` file inside (`next(n for n in z.namelist() if n.endswith('.txt'))`), extract to temp dir, use that path
3. Call `group_by_sender(path)` to get per-sender messages
4. Find matching sender: case-insensitive prefix match against `--sender` arg. If no match, print available senders and exit with error. If multiple matches, print them and exit with error.
5. Compute confidence from qualifying message count
6. Call `sample_messages()` then `extract_from_messages()` with OpenAI client
7. If `--dry-run`: print the PersonalityExtraction as formatted JSON (using `.model_dump_json(indent=2)`) and exit
8. If not dry-run: connect to DB, call `lookup_rider()` to find rider_id by sender name, call `store_extraction_results()` and `store_evidence()`, commit, print summary

**Error handling:**
- Missing OPENAI_API_KEY: print error and exit 1
- Missing DATABASE_URL (when not --dry-run): print error and exit 1
- Zero matching messages: print warning and exit 1
- OpenAI API errors: catch and print, exit 1

**Print summary at end:**
```
Extracted personality for {sender_name}:
  Qualifying messages: {count}
  Confidence: {level}
  Tone: {tone}
  Humor: {humor_type}
  ...
  Evidence quotes stored: {N}
```
