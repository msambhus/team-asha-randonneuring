1. Add `@api_login_required` decorator to `auth.py` (after the existing `@user_login_required` decorator):

```python
def api_login_required(f):
    """Require authentication for API endpoints. Returns 401 JSON on failure.
    Does NOT redirect — use @user_login_required for page routes instead.
    NEVER skips auth in debug mode — API endpoints must always enforce auth
    to prevent false-positive tests and accidental unauthenticated access.
    """
    @wraps(f)
    def decorated(*args, **kwargs):
        if not session.get('user_id'):
            return {'error': 'Authentication required'}, 401
        return f(*args, **kwargs)
    return decorated
```

CRITICAL: Unlike `@user_login_required`, this decorator has NO `if current_app.debug: return f(...)` bypass. API endpoints must always enforce authentication regardless of debug mode. This is per checker requirement and prevents false-positive auth tests.

2. Create `services/chat_service.py`:

```python
"""Chat service — moderation, message construction, streaming completions.

Security controls: moderation pre-filter, max_tokens enforcement, specific
error handling (no broad except Exception), prompt injection defense.
"""
import os
import json
import logging
from openai import OpenAI, RateLimitError, APITimeoutError, InternalServerError, APIError

logger = logging.getLogger(__name__)

# Module-level client (lazy init)
_client = None

def _get_client():
    global _client
    if _client is None:
        api_key = os.environ.get('OPENAI_API_KEY')
        if not api_key:
            raise RuntimeError("OPENAI_API_KEY not configured")
        _client = OpenAI(api_key=api_key)
    return _client
```

Functions to implement:

**`moderate_input(message: str) -> bool`**
- Call `_get_client().moderations.create(input=message, model="omni-moderation-latest")`
- Return `True` if safe, `False` if flagged
- If moderation API fails (any exception), return `False` (fail closed — SEC-04)
- Log the category if flagged (but NEVER log the message content — privacy)

**`build_messages(user_message: str, history: list[dict], system_prompt: str) -> list[dict]`**
- Return list starting with `{"role": "system", "content": system_prompt}`
- Append history messages (each has `role` and `content` keys)
- Append `{"role": "user", "content": user_message}` as last element
- CRITICAL (SEC-05): User content ONLY in `role: user`. Never concatenate user text into system prompt.
- Any DB-sourced data in system prompt must be wrapped in `<rider_data>...</rider_data>` delimiters

**`process_message(user_id: int, message: str, conversation_id: str | None) -> generator`**
This is the main SSE generator. Steps:
1. Call `moderate_input(message)`. If flagged, yield error SSE and return.
2. If `conversation_id` is None, call `models.create_conversation(user_id)` to get a new one. If provided, call `models.get_conversation(conversation_id, user_id)` — if None returned (wrong user or doesn't exist), yield error SSE and return.
3. Call `models.insert_chat_message(conversation_id, 'user', message)` to persist the user message.
4. Call `models.get_recent_messages(conversation_id, limit=20)` to get history (SEC-07).
5. Import `CHAT_SYSTEM_PROMPT` from `services.openai_coach` (created in Plan 03). Fallback: if `CHAT_SYSTEM_PROMPT` is not defined yet, use a minimal placeholder: "You are a cycling and randonneuring coaching assistant for Team Asha."
6. Call `build_messages(message, history, system_prompt)`.
7. Yield `data: {"conversation_id": "<id>"}\n\n` as first SSE event (so client knows the conversation ID).
8. Stream the completion via `_stream_completion(messages)`, accumulating the full response.
9. After streaming completes, call `models.insert_chat_message(conversation_id, 'assistant', full_content, prompt_tokens, completion_tokens)`.
10. Call `models.touch_conversation(conversation_id)`.

**`_stream_completion(messages: list[dict]) -> generator`**
- Call `_get_client().chat.completions.create(model="gpt-4o-mini", messages=messages, max_tokens=700, stream=True, stream_options={"include_usage": True}, timeout=50)`
- For each chunk: if `chunk.choices` and `chunk.choices[0].delta.content`, yield `f"data: {json.dumps(token)}\n\n"` (JSON-encode individual tokens to handle special chars)
- Track `full_content` by accumulating tokens
- If `chunk.usage` exists (final chunk with `stream_options`), capture `prompt_tokens` and `completion_tokens`
- Catch `RateLimitError` -> yield `'data: {"error": "I\'m handling too many requests right now. Please try again in a moment."}\n\n'`
- Catch `APITimeoutError` -> yield `'data: {"error": "That took too long. Please try a shorter question or try again."}\n\n'`
- Catch `InternalServerError` -> yield `'data: {"error": "There\'s a temporary issue with the AI service. Please try again."}\n\n'`
- Catch `APIError` (base class for others) -> yield generic error
- Do NOT use bare `except Exception` (SEC-08, Pitfall 3)
- Return a tuple `(full_content, prompt_tokens, completion_tokens)` — use a mutable container since generators can't return values directly. Use a list or dict as accumulator passed to the generator.

```python
"""Chat API routes — SSE streaming endpoint."""
from flask import Blueprint, Response, request, session, stream_with_context
from auth import api_login_required  # NOT user_login_required — must return 401, not 302
import services.chat_service as chat_service

chat_bp = Blueprint('chat', __name__)

@chat_bp.route('/api/chat/stream', methods=['POST'])
@api_login_required
def chat_stream():
    data = request.get_json(silent=True)
    if not data:
        return {'error': 'Invalid JSON'}, 400

    message = (data.get('message') or '').strip()
    conversation_id = data.get('conversation_id')
    user_id = session.get('user_id')

    # Input validation (SEC-09) — before any processing
    if not message:
        return {'error': 'Message required'}, 400
    if len(message) > 2000:
        return {'error': 'Message too long (max 2000 characters)'}, 400

    def generate():
        try:
            for chunk in chat_service.process_message(
                user_id=user_id,
                message=message,
                conversation_id=conversation_id,
            ):
                yield chunk
        except Exception as e:
            # Last resort — should not reach here if chat_service handles errors properly
            yield f'data: {{"error": "Something went wrong. Please try again."}}\n\n'
        yield "data: [DONE]\n\n"

    return Response(stream_with_context(generate()), mimetype='text/event-stream')
```
