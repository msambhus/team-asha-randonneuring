Two parts: the API endpoint and the widget wiring.

**1. API Endpoint (`routes/chat.py`):**

Add a new route to the `chat_bp` blueprint:

```python
@chat_bp.route('/api/chat/conversations', methods=['GET'])
@api_login_required
def list_conversations():
    user_id = session.get('user_id')
    convs = models.get_conversations_for_user(user_id, limit=20)
    return {
        'conversations': [
            {
                'id': str(c['id']),
                'title': c.get('title') or 'Untitled conversation',
                'last_active_at': str(c['last_active_at'])[:16].replace('T', ' '),
            }
            for c in convs
        ]
    }
```

Import `models` at the top if not already imported. The `@api_login_required` decorator handles auth gating. `get_conversations_for_user()` already filters by `user_id` (SEC-10).

**2. Widget Wiring (`templates/chat_widget.html`):**

The Plan 01 widget already has `showConversationList()`, `hideConversationList()`, and `loadConversation()` stubbed. Update them to be fully functional:

- `showConversationList()`: Should already fetch from `/api/chat/conversations` and render the list. Verify it handles empty conversations list ("No conversations yet."), loading state, and fetch errors. Each conversation item should be clickable and show title + last_active_at.

- `loadConversation(convId)`: When loading a previous conversation, fetch its recent messages to display history in the widget. Add a new fetch to `GET /api/chat/conversations/{convId}/messages` OR use the existing behavior where the server loads history on next message send. The simpler approach (per research): just set `currentConversationId = convId`, clear messages, show a system note "Conversation loaded. Continue where you left off." The server will load the last 8 turns when the next message is sent. This avoids needing a new endpoint.

- `newConversation()`: Verify it clears `currentConversationId = null`, clears messages div, shows system note "New conversation started." (CHAT-07). This is already stubbed in Plan 01.
